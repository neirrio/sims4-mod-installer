# Sims 4 Auto Mod Installer v2.1

Автоматический установщик модов для The Sims 4 с настоящим drag-and-drop и расширенной поддержкой форматов.

## Новые возможности в v2.1

### � Настоящий Drag-and-Drop
- Реализован через библиотеку tkinterdnd2
- Визуальная обратная связь при наведении
- Поддержка множественного перетаскивания файлов
- Автоматическая обработка путей Windows

### 📦 Расширенная поддержка форматов
- **`.package`** - основные файлы модов
- **`.ts4script`** - скриптовые моды  
- **`.zip`** - ZIP архивы
- **`.7z`** - 7-Zip архивы (через py7zr)
- **`.rar`** - RAR архивы (через rarfile)
- **`.exe`** - инсталляторы и SFX архивы

### 🔧 Умная обработка архивов
- Автоматическое определение типа архива
- Извлечение только .package и .ts4script файлов
- Поддержка пароленных архивов (для ZIP)
- Обработка SFX архивов через 7z командной строки

### 📁 Инсталляторы модов
- Распознавание SFX архивов
- Автоматическое извлечение при возможности
- Ручной запуск для обычных инсталляторов
- Открытие папки модов в один клик

### 🎨 Улучшенный интерфейс
- Добавлены кнопки "О программе" и "Настройки"
- Интерактивная область drag-and-drop
- Визуальные подсказки и обратная связь
- Адаптивный размер окна

## Установка и использование

1. Запустите файл `sims4_mod_installer.py`
2. Программа автоматически найдет игру или укажите путь вручную
3. Используйте любой из способов установки:
   - URL для прямого скачивания
   - Выбор локального файла
   - Drag-and-drop файлов
   - Автоматическая установка из списка

## Поддерживаемые форматы

- **`.package`** - основные файлы модов
- **`.ts4script`** - скриптовые моды  
- **`.zip`** - ZIP архивы
- **`.7z`** - 7-Zip архивы
- **`.rar`** - RAR архивы
- **`.exe`** - инсталляторы и SFX архивы

## Системные требования

- Windows 7/8/10/11
- Python 3.6+
- The Sims 4 (любая версия)
- **Дополнительно для расширенных форматов:**
  - `tkinterdnd2` - для настоящего drag-and-drop
  - `py7zr` - для 7Z архивов
  - `rarfile` - для RAR архивов
  - `7-Zip` - для SFX архивов (рекомендуется)

## Установка зависимостей

```bash
pip install tkinterdnd2 py7zr rarfile
```

## Особенности использования

### Drag-and-Drop
- Просто перетащите файлы в серую область
- Поддерживается множественное выделение
- Визуальная обратная связь при наведении

### Архивы
- Программа автоматически извлечет .package и .ts4script файлы
- Поддерживаются вложенные папки в архивах
- Автоматическое разрешение конфликтов имен

### Инсталляторы
- SFX архивы распаковываются автоматически
- Для обычных EXE открывается папка модов
- Возможен запуск инсталлятора в один клик

## Настройки

В окне "Настройки" можно настроить:
- Пути к игре и папке модов
- Параметры скачивания
- Поведение интерфейса
- Автоматизацию

## Горячие клавиши

- **Ctrl+V** - вставить URL из буфера обмена

## Безопасность

- Все файлы проверяются перед установкой
- Поддерживаются только проверенные форматы
- Автоматическое создание резервных копий
