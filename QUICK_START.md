## 📋 Что готово:

✅ **Автоматические обновления через GitHub Releases**  
✅ **Уникальные токены устройств**  
✅ **Режим технических работ**  
✅ **GitHub Actions для сборки**  
✅ **Сравнение версий**  
✅ **Загрузка обновлений**  

## ⚡ Быстрая настройка (5 минут):

### 1. Настройте GitHub репозиторий
```bash
# Создайте репозиторий на GitHub: sims4-mod-installer
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ВАШ_НИК/sims4-mod-installer.git
git push -u origin main
```

### 2. Измените настройки программы
Откройте `sims4_mod_installer.py` и замените:
```python
self.github_owner = "ВАШ_НИК"  # Ваш ник на GitHub
self.github_repo = "sims4-mod-installer"  # Имя репозитория
```

### 3. Создайте первый релиз
```bash
git tag v2.1.0
git push origin v2.1.0
```

### 4. Готово! 🎉
Программа автоматически будет проверять обновления при запуске.

## 🎯 Как это работает:

### 🔄 Проверка обновлений
- При запуске программа проверяет GitHub Releases
- Сравнивает версии (v2.2.0 > v2.1.0)
- Показывает диалог обновления

### 📦 Установка обновлений
- Скачивает ZIP с GitHub
- Распаковывает и заменяет файлы
- Автоматически перезапускается

### 🔧 Режим обслуживания
- Создайте `maintenance.json` в репозитории:
```json
{"enabled": true, "message": "Технические работы..."}
```
- Программа покажет оверлей и заблокируется

### 📱 Статистика устройств
- Уникальный токен для каждого устройства
- Анонимная статистика использования
- Отслеживание версий

## 🛠️ Управление:

### Создание обновления
```bash
# Новая версия
git tag v2.2.0
git push origin v2.2.0

# Обязательное обновление
git tag v2.2.0-mandatory
git push origin v2.2.0-mandatory
```

### Режим обслуживания
```bash
# Включить
echo '{"enabled": true, "message": "Работы..."}' > maintenance.json
git add maintenance.json && git commit -m "Maintenance" && git push

# Выключить
echo '{"enabled": false}' > maintenance.json
git add maintenance.json && git commit -m "Maintenance off" && git push
```
