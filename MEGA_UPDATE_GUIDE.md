## 🛠️ Настройка сервера

### 1. Установка зависимостей сервера
```bash
pip install flask
```

### 2. Запуск сервера
```bash
python server.py
```
Сервер будет доступен на `http://localhost:5000`

### 3. Админ-панель
Откройте `http://localhost:5000` в браузере для доступа к панели управления.

## 📱 Настройка клиента

### 1. Обновление URL сервера
В файле `sims4_mod_installer.py` измените:
```python
self.update_server_url = "http://localhost:5000/api"  # Для локального теста
# или
self.update_server_url = "https://your-server.com/api"  # Для продакшена
```

### 2. Запуск программы
```bash
python sims4_mod_installer.py
```

При первом запуске программа:
- Сгенерирует уникальный токен устройства
- Зарегистрируется на сервере
- Начнет проверку обновлений

## 🔄 Процесс обновления

### 1. Создание обновления
1. Зайдите в админ-панель
2. Заполните форму обновления
3. Укажите URL для скачивания
4. Нажмите "Создать обновление"

### 2. Установка на клиентах
1. Клиенты автоматически проверят обновления
2. Появится диалог обновления
3. Программа скачает и установит обновление
4. Автоматический перезапуск

### 3. Обязательные обновления
- Блокируют работу программы до установки
- Автоматически устанавливаются
- Показывают уведомление о необходимости

## 🚀 Развертывание

### Локальное тестирование
1. Запустите сервер: `python server.py`
2. Измените URL в клиенте на `http://localhost:5000/api`
3. Запустите клиент: `python sims4_mod_installer.py`

### Продакшен развертывание
1. Разместите сервер на VPS/хостинге
2. Настройте HTTPS сертификат
3. Измените URL в клиенте на ваш домен
4. Соберите дистрибутив для распространения

## 📝 Файлы конфигурации

### device_token.json
```json
{
    "token": "uuid-token",
    "device_id": "hashed-id",
    "created_at": "2024-01-01T00:00:00",
    "version": "2.1",
    "system_info": {...}
}
```

### maintenance_mode.json
```json
{
    "enabled": false,
    "message": "",
    "updated_at": "2024-01-01T00:00:00"
}
```

### devices.db
SQLite база данных с таблицами:
- `devices` - информация об устройствах
- `updates` - информация об обновлениях
- `maintenance` - режим обслуживания

## 🔧 Поиск проблем

### Ошибки подключения
- Проверьте URL сервера
- Убедитесь что сервер запущен
- Проверьте сетевые настройки

### Обновления не устанавливаются
- Проверьте URL скачивания
- Убедитесь что файл доступен
- Проверьте права доступа

### Устройства не регистрируются
- Проверьте логи сервера
- Убедитесь в доступности API
- Проверьте токен устройства
